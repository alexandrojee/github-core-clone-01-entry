# GitHub Core Clone — make.fun bounty github-core-clone-01

Standalone GitHub-compatible git forge in TypeScript (Node 22 stdlib only). Serves git smart HTTP (upload-pack v2), REST v3 under /api/v3, GraphQL v4 at /api/graphql, and MCP at /mcp. Runs as one process, binds an ephemeral port, registers with MAKEFUN_ENV_URL.
